\chapter{Branching bisimilarity}

En este capitulo introduciremos las definiciones de Branching bisimilarity y de Weak Sythesis Observational Equivalence (WSOE) para utilizarlos como fundamentos a la hora de minimizar un LTS. Con el objetivo de minimizar un LTS en el contexto de la sintesis composicional, utilizamos alguna definicion para poder aplicarla a la hora de procesar los estados y definir que nocion de equivalencia utilizar a la hora de decidir si son equivalentes o no. En principio, en el algoritmo de sintesis composicional presentado por Uchitel y Gagliardi se utiliza la definciion de WSOE. Tal como se explico anteriormente, esta tesis consiste en analizar el reemplazo del algoritmo que utiliza la definicion de WSOE por el algoritmo de Jansen que utiliza la defincion de Branching bisimilarity. Para ello, este capitulo introducira de forma teorica ambas equivalencias y presentara un teorema de como se relacionan entre ellas.

\section{Definición formal}
La Definición~\ref{def:branching} introduce la nocion de equivalencia denominada Branching bisimulation. Dada una relacion de equivalencia $R$, una transicion $s\pijl{a}t$ es denotada \textit{inerte} sii $a = \tau$ y  $\R{s}{t}$.

El conjunto de acciones $a$ tal que $a = \tau$ forma parte del conjunto de datos que se deben proveer al comenzar el proceso de minimizacion.

\begin{definition}[Branching bisimilarity]
\label{def:branching}
Sea $M = (S, \Sigma, \xrightarrow[]{}, \hat{s})$ un LTS.
Definimos una relacion  $R\subseteq S\times S$
como una relacion de \emph{branching bisimulation} sii es simetrica y para todo $s,t\in $ vale que $\R{s}{t}$
y para todas las transiciones $s \pijl{a} s'$ tenemos:
\begin{enumerate}
\item
$a=\tau$ y $\R{s'}{t}$, o
\item   \label{def:branching:simulating-transition}
existe una secuencia
$t\pijl{\tau}\cdots\pijl{\tau} t'\pijl{a}t''$
tal que $\R{s}{t'}$ y $\R{s'}{t''}$.
\end{enumerate}
Los estados $s$ y $t$ son \emph{branching bisimilar,} denotado como $s \bbis t$,
sii existe una relacion de  \emph{branching bisimulation} $R$ tal que
$\R{s}{t}$.
\end{definition}

\begin{definition}[Weak synthesis observation equivalence~\cite{mohajerani_framework_2014}]
    \label{def:synth-equiv}
    Sea $M = (S, \Sigma, \xrightarrow[]{}, \hat{s})$ un LTS y sea $\Sigma_c$ el conjunto de eventos controlables y sea $\Sigma_u$ el conjunto de eventos no-controlables. Una relacion de equivalencia $\sim_{\Upsilon} \ \subseteq S \times S$ es del tipo \textit{weak synthesis observational equivalence} con $M$ respecto al conjunto de etiquetas $\Upsilon_c$ y $\Upsilon_u$ si las siguientes condiciones valen para todo $x_1, x_2 \in S$ tal que $x_1 \sim_{\Upsilon} x_2$:
\vspace{-0.2pt}
    \begin{enumerate}
        \item si $x_1 \xrightarrow[]{u} y_1$ para $u \in \Sigma_u$, entonces existen transiciones ''invisibles'' $\tau \in \Upsilon_u^{*}$ tal que
        existe una secuencia
        $x_2\pijl{\tau}\cdots x_2' \pijl{u} y_2' \cdots\pijl{\tau} y_2$ y $y_1 \sim_{\Upsilon} y_2$
        \item si $x_1 \xrightarrow[]{c} y_1$ para $c \in \Sigma_c$, entonces existe un camino $x_2 = x_2^{0} \xrightarrow[]{\tau_1} ... \xrightarrow[]{\tau_n} x_2^{n} \xrightarrow[]{P_{\Omega}(c)} y_2$ tal que $y_1 \sim_{\Upsilon} y_2$ y $\tau_1, .., \tau_n \in \Upsilon$, y si $\tau_{i\in\{1 .. n\}} \in \Sigma_c$ entonces $x_1 \sim_{\Upsilon} x_2^i$
    \end{enumerate}
\end{definition}
